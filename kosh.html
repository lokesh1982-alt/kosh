Binance sync
Lead Trading and Spot are kept in sync automatically from your Binance account's real trade history — no manual entry. Binance has no "lead trading vs personal" concept of its own, so a symbol map below decides which portfolio each traded pair routes to. "Spot" is Kosh's name for your regular Binance Spot wallet — not to be confused with Binance's own "Alpha" zone for pre-listed tokens, which has no API and is tracked as a separate manual portfolio instead.
⚠️ Lead Trading lives in a separate Binance wallet from your regular account (that's why "Copy Trading API" is a different button on Binance) — your regular API key can't see it. Create a second key in the Binance app: Trade → Copy Trading → Spot → your portfolio → [API] → Create Copy Trading API, then add it in Supabase as BINANCE_LEAD_API_KEY / BINANCE_LEAD_API_SECRET, alongside your existing BINANCE_API_KEY / BINANCE_API_SECRET (which stays as-is, used for Spot and Funding).
💡 Want your Funding wallet tracked too? Create a portfolio named exactly "Funding Wallet" (+ New in the portfolio switcher) — every sync will then reconcile its balances automatically, the same way Spot's holdings stay current.
